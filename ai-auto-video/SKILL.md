# AI 自动化剪辑：全流程与单步调用

Agent串联真实工具完成制作。先确定调用范围；已有项目读取 `project.json`、`STATUS.md` 和用户最新决定。已有脚本、环境与成功记录优先复用，不为重复验证再次生成。

## 调用范围

- **全流程**：用户要求做成片时，按下表依赖顺序组合所需环节，从首个未完成阶段续做。
- **单步或多步**：用户说“只做某步”、列出几个环节或要求局部修改时，仅执行指定范围，检查并交付后停止，不自动推进后续制作。表中名称是自然语言路由，不是新增 CLI 子命令。
- **只讲方法**：用户问“怎么生成”“提示词怎么写”时，读取对应文档解释方法、输入和示例，不自动安装、生成或调用付费服务。
- 单步先核对下表最小输入；已有产物直接使用，缺项只补当前步必需部分。需扩展到未请求的生成阶段时说明缺项并询问，不默默补跑全链路。纯文案或视觉草案不要求先配音。
- 只检查本次所需工具。没有项目时可在用户输出目录交付独立文档/图片；需要随包脚本时建立最小项目目录，初始化不代表所有阶段已完成。状态与下游失效按 [contracts.md](references/contracts.md)；阶段检查按 [testing.md](references/testing.md)。

## 开工与执行方式

- 需要选题的环节，缺少选题且无法推断时询问。规格优先沿用已有输入；新建整片未指定时可默认中文、60–90秒、1920×1080、30fps，角色风格沿用账号，指定竖屏则使用1080×1920。单步只补与该步有关的规格。
- 自动制作按已授权范围自检后继续；共创只停在用户指定节点。决策区分 `agent-selected` 与 `user-approved`，最终采用版本及旧产物删除按收尾规则确认。
- 定位实际 Skill 目录为 `SKILL_ROOT`。按本次范围读取 [方案选择](references/providers.md) 盘点必要能力、说明可行方案的优劣；需初始化时按 [工作区初始化](references/workspace.md) 创建分区和素材库、补齐所选依赖。没有前置试听环节。
- 工具调用及命令见 [tools.md](references/tools.md)；项目字段、依赖失效和素材账本见 [contracts.md](references/contracts.md)。

## 阶段路由：输入、产出与停止位置

每行均可独立调用；全流程按依赖顺序组合，素材整理、音频拆分等按需执行，已有可用产物直接复用。详细要求只在对应文档定义。

| 调用环节 | 最小输入 | 产出，完成后可停在此处 | 执行说明 |
|---|---|---|---|
| 方案选择 | 效果要求、现有工具与预算约束 | 可行路线及优劣，不发起生成 | [providers.md](references/providers.md) |
| 环境与项目初始化 | 工作区位置、待执行环节 | 依赖检查、项目分区与素材库 | [workspace.md](references/workspace.md) |
| 素材整理 | 指定素材目录与整理目标 | 盘点、分类及选中素材索引 | [workspace.md](references/workspace.md) |
| 角色设计 / 三视图 | 角色需求；三视图需身份原图 | 角色图或同一身份三视图与检查记录 | [visual-prompts.md](references/visual-prompts.md) |
| 口播文案 | 选题、受众、长度要求 | narration.txt、screen-plan.md | [writing.md](references/writing.md) |
| 配音 / 音频导入 | 定稿、已选声线或已有音频 | 整段配音及完整性检查 | [audio.md](references/audio.md) |
| 对齐与字幕 | 定稿及对应完整音频 | 真实时间轴、字幕及对齐检查 | [audio.md](references/audio.md) |
| 音频拆分 | 已校验音频与时间轴 | 采样点切片及 segments.json | [audio.md](references/audio.md) |
| 视觉编排 / 视觉编排图 | 文案、画幅；有角色时提供参考 | 文字分镜、可视编排图；有对齐才生成正式时间分镜 | [visual-prompts.md](references/visual-prompts.md) |
| 人物镜头 / A-roll | 本镜设计及所需角色、场景参考 | 指定镜头图片或所选路线的视频片段 | [visual-prompts.md](references/visual-prompts.md) |

| 混音 | 现有音轨或视频、所需音乐/音效 | 新混音版本及检查，保留未要求改动的画面 | [audio.md](references/audio.md) |
| 合成 / 渲染导出 | 可用工程，或已齐备的镜头、音频与时间轴 | 可重渲染工程或 MP4 | [tools.md](references/tools.md) |
| 检查验收 | 指定阶段产物或成片 | 该范围的检查报告；仅检查时不重做素材 | [testing.md](references/testing.md) |
| 版本选择与清理 | 实际版本、引用关系与用户选择 | 保留/删除清单；确认清单与方式后才删除 | [versions-and-cleanup.md](references/versions-and-cleanup.md) |

## 修改本 Skill 的规则

- 修改前先查已有内容，确定负责该环节的文档；生图要求改生图文档，音频要求改音频文档，不另建“补充要求”或“补漏清单”。
- 原位替换错误、过时或不完整的说明，删除被替代内容；不在末尾追加一条与旧规则并存的新说法。
- 同一规则只保留一个完整定义，其他文档确需使用时链接过去。每份文档各司其职，入口只保留流程、关键边界与阅读路由。
- 只有现有文档无法合理承载一个独立职责时才新增文件；不因一次反馈就增加文件、章节或检查项。项目专属偏好留在项目配置中。
- 修改后通读相关文档，合并重复、消除冲突、检查引用与实际脚本是否一致；删除无助于执行的解释和历史修改过程，保持重点清晰。脚本变更只验证受影响行为，不重复运行已有充分证据的生成流程。
