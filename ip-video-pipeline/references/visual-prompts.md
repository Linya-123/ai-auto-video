# 角色、分镜与画面制作

## 采用素材与身份基准

先核对最新确认和否决记录，将本片角色、场景与镜头映射到真实文件。实际查看参考图，不以文件存在、名字含final或旧报告通过推定用户批准。已否决图片及其副本不得进入生成参考或成片；可用哈希识别副本。

区分身份、场景、笔触、机位参考的用途。外部示例只能借鉴所需设计，不误当用户的角色或开场。优先参考最接近目标机位的已采用成图，记录人物与家具的空间关系，不只抽取配色。

首次角色生成一个原创方向，用户需要比较时再出候选。三视图使用同一身份原图：正/侧/背同高度、同尺度、完整留白，保持五官、发型、服饰、左右定义和头身比；未展示部位的设计补全另记。从已采用原图裁取笔触细节，不另生“类似风格”替代。场景保持具体环境及前后层次。

## A-roll 单镜生成

输入本镜设计和所需身份、三视图、笔触、场景参考。明确角色在何处做什么、视线目标、景别、机位、人物与桌面前后关系，以及本镜最终结果。字幕和精确文字后期叠加；看板、纸面或屏幕提前留出可读的承载面积，不能为留白擅自清空已确认环境。

视角按叙事需要选择，不轮换打卡：主持人面向观众讲解；主角在场景里行动；配角承担被解释行为；第一人称展示主角观察或操作的对象。

验图检查身份、比例、左右、眼神、手腕衣袖连接、手与道具接触、前景手部归属和透视、桌面遮挡及关键部位裁切。近大远小本身不是错误，要看空间是否成立；遮挡不可见处不声称已验证。叠加便签或按钮须处理前后层级，避免盖住手或道具悬空。

实际结果与提示词不同但仍可表达原意时，按授权采用并更新描述；不声称完全按提示词执行。记录问题，只返工受影响镜头。需要生成视频片段或口型时按 [方案选择](providers.md) 接入相应能力，插画动效不冒充对口型视频。

## 分镜与B-roll

时间取自 `audio/vo-align.json`，一个镜头可覆盖多个连续短语，不机械逐句切镜。字段按 [文件契约](contracts.md)；每镜明确“理解目标、口播锚点、对象动作、结束结果和衔接”，不用“高级、丰富、有节奏”代替设计。

| 语义 | 应发生的变化 |
|---|---|
| 对比 | 同尺度并列，在明确维度上看出差别 |
| 筛选 | 规则作用于候选，结果只留下通过项 |
| 聚合 | 分散对象进入共同类别 |
| 层级 | 展开父子关系，保持层级线索 |
| 因果 | 已证实的条件变化引起结果变化 |
| 替换 | 旧对象在稳定位置被新对象接替 |
| 步骤 | 高亮当前步骤，保留必要的完成状态 |

先匹配本地语义模板，不足再查 HyperFrames catalog 或 [工具资料](tools.md)。读具体源码与许可后适配；Remotion源码不能直接塞进HyperFrames。运动要推进关系，不用无意义漂浮、每词弹跳或反复卡片入场代替解释。短段可延续构图，长镜头用局部变化推进。

案例输入、生成输出、真实录屏与示意图分清；素材不匹配就补齐或调整表达，不拿相似图充数。缺少关键演示素材明确待补，不能当完成品。

## 排版与动画布局

同级标题、正文、标签使用统一字体、字号、真实字重、颜色和间距变量，避免内联样式与合成粗体破坏一致性；必要时核查实际加载字体与计算样式。按最终画幅检查阅读大小，不固化某片字号。

同类元素共享基线，高亮框贴合目标；连线端点跟随节点几何与动画，SVG viewBox匹配显示坐标，节点未出现时不留孤立线段。节点移动后复查端点。

录屏与案例图优先保留比例、原色和可读区域。设备框、圆角、底板、连线只有表达需要才加；来源说明放稳定的次要位置。字幕、正文、UI不必全挤同屏，留白通过构图解决，避免主体过小或字幕抢过内容。

检查入场、关系变化、转场交界和终态：文字不跨场景重叠，高亮不早于真实关键词，内容不被新元素遮挡，线条中途不偏位。只看终态截图不能证明动态正确。
